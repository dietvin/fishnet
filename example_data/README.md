# Example data

This directory contains a selection of minimal test data from different pores and analytes. These are:
- [DNA R10](./DNA_R10/) 
- [RNA004](./RNA004/) 
- [DNA R9](./DNA_R9/) (legacy)
- [RNA002](./RNA002/) (legacy)

Each directory contains a single POD5 and BAM file with 100 reads, and a minimal processing script that was used to generate the data. The processing script contains steps to download, basecall, map and subset given data.

## Data origins
The RNA002 and RNA004 is taken from [Hewel et al. (2025)](https://doi.org/10.1093/nar/gkaf1314). DNA R10 and R9 data stem from [Sanderson et al. (2023)](https://doi.org/10.1099/mgen.0.000910).
